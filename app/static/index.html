Add a provider key

Keys are read from environment variables, or from a keys file mounted into the container.

# docker run
docker run -e DEEPSEEK_API_KEY=... -e OPENROUTER_API_KEY=... -p 127.0.0.1:8760:8000 ghcr.io/abdulazizalmalki-gh/ai-credit-watch:latest

# docker compose — keys and bind address live in .env next to it
DEEPSEEK_API_KEY=...
OPENROUTER_API_KEY=...
CREDIT_WATCH_BIND=192.0.2.50   # this host's LAN IP (default 127.0.0.1, never 0.0.0.0)
